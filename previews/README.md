# UI previews

`home-current.png` shows the current Home screen in the shared browser UI adapter at 390 pixels. It is not a physical-phone screenshot. Earlier `fire-mobile.jpg` and `offline-mobile.jpg` are retained historical previews from the previous redesign and do not represent the current real-street renderer.

Renderer and full-flow checks use controlled OSM-format fixtures when live public road services are unavailable. Fixture map screenshots are not shipped as evidence of real geographical downloads.
