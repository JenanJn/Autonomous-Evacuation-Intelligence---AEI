This is your existing project, enhanced. Home is restored.
Current Location / Choose on Map / Demo Mode -> select disaster -> prepare location -> choose shelter -> navigate.

RUN ON A PHONE
1. Stop older Expo terminals with Ctrl+C.
2. Open AEI and double-click RUN-MOBILE.cmd.
3. Let missing dependencies install. Keep phone and computer on the same Wi-Fi.
4. Scan the QR code using Expo Go compatible with SDK 53.
This release stays on SDK 53. SDK 57 Expo Go cannot open SDK 53 projects.
For an APK independent of Expo Go, follow README-LOCATION-INDEPENDENT.md.

DEMONSTRATE
Choose any location with mapped public roads; no fixed city or campus is required.
Internet is needed to prepare a new area. Public road services can be slow or unavailable.
Choose Flood, Fire, Cyclone, Earthquake or Landslide before preparing.
Start navigation, then Trigger Blockage Ahead to show automatic recalculation.
Demo walk advances along the actual route. Fill shelter demonstrates destination fallback.
Training studio has check-ins, hazard expansion and optional server publishing.
View surroundings opens external Google Maps imagery where available.

OFFLINE
The last downloaded area's actual street vectors, graph, hazards and shelters are saved locally.
Detailed online tiles and street imagery require connectivity. No standard OSM tile bulk-download is used.
New locations outside the saved area need a new download. An installed APK is needed for an independent cold start.

OPERATIONS
Optional server: python demo/server.py
Dashboard: http://localhost:8080/operations.html
See README-LOCATION-INDEPENDENT.md for LAN setup, authentication, publish-first flow and APK instructions.

All disaster events and shelter occupancy are simulated. Real push/SMS providers and official shelter data are not connected.
