AEI - COMPLETE MOBILE REDESIGN

Everything is included. You do not need earlier ZIP files.

EASIEST WAY TO RUN ON WINDOWS
1. Extract the complete ZIP into a NEW folder.
2. Open the AEI folder.
3. Double-click RUN-MOBILE.cmd.
4. Let dependency installation finish if this is the first launch.
5. Keep laptop and phone on the same Wi-Fi.
6. Scan the new QR code with Expo Go for SDK 53 (Android).

Node.js 20 or later is required. The launcher detects the laptop Wi-Fi IPv4 address and uses it for the QR code, rather than 127.0.0.1. If Windows asks, allow Node.js on your trusted Private network. It does not change firewall or persistent system settings itself.

ALREADY HAVE EXPO GO FOR SDK 53?
Keep it. This release remains SDK 53 and includes the SDK 53 package compatibility updates.
Official SDK 53 Android download:
https://expo.dev/go?sdkVersion=53&platform=android&device=true

MANUAL METHOD
Open PowerShell in AEI/mobile:
  npm ci
  node scripts/start-phone.cjs

USE THE APP
Tap Use my current location, then Find safe shelter.
Choose a shelter, View this route, then Start navigation.
SOS is always at the top. Map key and offline readiness are in the menu.

CHANGE THE DEMO DISASTER
Menu (top-right) -> Training studio -> Flood / Fire / Cyclone / Earthquake / Landslide -> Close.
Return to the map to see water or flames, or the relevant disaster symbols.

DEMONSTRATE REROUTING
Start navigation first. Then Menu -> Training studio -> Block the road ahead.
For shelter fallback, choose Make this shelter unreachable instead.
Training actions automatically return to the map. Demo walking can advance one road for the presentation.

OFFLINE
Menu -> Offline readiness -> Save route data now.
Use the schematic map when the street basemap is unavailable.
Full offline street-map downloads are NOT included.
Expo Go normally needs Metro for a cold start. A standalone native build is needed to launch independently from the development computer.

IMPORTANT
All hazards, road overlays, shelters and medical facilities are simulated training data. No official disaster feed or emergency dispatch is connected. This is source code, not an APK. Native phone/field testing is still needed.
